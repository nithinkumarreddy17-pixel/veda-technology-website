# Veda Technology Business & Services Website

A professional, responsive business website project created for Veda Technology.

The website presents technology programs, internship opportunities, training information, digital services, FAQs, contact information, and an internship application flow through a clean and modern interface.

---

## 📌 Project Overview

The Veda Technology website is designed as a central platform for presenting:

- Technology programs
- Internship opportunities
- Training and practical learning information
- IT and digital services
- Frequently Asked Questions
- Contact information
- Internship application form

The project focuses on responsive design, reusable UI components, clear navigation, JavaScript interactions, and a professional technology-business visual style.

---

## 🎯 Project Objective

The objective of this project is to create a professional multi-section technology-business website while applying:

- Responsive web design
- HTML5 semantic structure
- CSS3 styling
- CSS Grid and Flexbox
- JavaScript interactions
- Form validation
- Responsive navigation
- Reusable components
- Basic SEO practices
- Git and GitHub workflow
- Website deployment

# 🎓 Internship Section

The internship section provides information about:

- Training Programs
- Internship Opportunities
- Practical Learning

The Internship Opportunities card includes an **Apply Now →** button that opens the internship application page.

---

# 📝 Internship Application

The separate internship application page includes fields for:

- Full Name
- Gender
- Mobile Number
- Email Address
- Internship Domain
- Highest Academic Qualification
- College Name
- LinkedIn confirmation
- WhatsApp confirmation
- Terms & Conditions
- Additional information
- Submit Application

The application page is connected to the Apply Now buttons on the website.

---

# 🔗 Apply Now Functionality

Program buttons can open the application page with a selected internship domain.

Example:

```html
<a
    href="internship-application.html?domain=Web%20Development"
    class="program-apply"
>
    Apply Now →
</a>
